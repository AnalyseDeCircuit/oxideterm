# 便携 `.oxide` 包

`.oxide` 是加密的便携导入导出包，用于在机器或配置档之间迁移 OxideTerm 数据。它可以包含连接、转发、应用设置、快捷命令、插件设置、托管 SSH 密钥，以及可选的便携凭据。

普通导入导出优先使用桌面应用，这样可以在应用里预览变更后再执行。

## 导入前预览

打开便携导入页面，选择 `.oxide` 文件，先预览内容再导入。重点检查：

- 包里包含哪些连接、转发、设置、快捷命令和插件设置。
- 是否包含托管 SSH 密钥，以及是否会恢复到 OxideTerm。
- 是否包含便携凭据。
- 哪些记录会和当前配置档冲突。
- 将使用哪种冲突策略。

预览结果不符合预期前，不要导入便携包。

## 导入策略

选择冲突策略：

- `skip`：保留已有本地记录。
- `rename`：冲突记录用新名字导入。
- `replace`：替换本地记录。
- `merge`：合并兼容记录。

使用能满足任务的最小策略。例如，只是查看另一台机器的包时优先使用 `skip` 或 `rename`；只有明确要让包覆盖本地记录时才用 `replace`。

## 导出

在导出页面选择要包含的内容。添加清晰描述，方便目标机器之后识别这个便携包。

凭据材料是显式选项：

- 保存的服务器密码默认不包含。
- 外部私钥文件只有启用嵌入时才会复制进包。
- 已保存的密钥或证书 passphrase 有单独的可见选项。
- OxideTerm 托管 SSH 密钥可以包含进包，使托管密钥连接在导入后恢复到托管密钥库。
- 托管密钥 passphrase 默认不包含，除非导出时显式开启。
- 便携凭据用于便携迁移等自包含配置档迁移场景。

只有目标机器需要加密凭据材料时，才包含便携凭据。只有明确需要把私钥文件或托管密钥放进加密包时才开启，并确保便携包密码足够强。

## 托管 SSH 密钥

托管密钥是 OxideTerm 自己管理的凭据。连接配置只保存托管密钥引用，私钥材料保存在本地钥匙串或便携密钥库中。

当包里包含托管密钥时，导入预览会允许恢复到 OxideTerm。若关闭恢复，OxideTerm 可以在可用时使用内嵌 fallback 密钥文件；否则受影响连接导入后需要修复认证配置。

重复托管密钥按 fingerprint 匹配，应复用已有密钥，而不是再创建一份副本。

## Cloud Sync 边界

云同步按所选范围上传加密快照。密码、托管私钥、AI 密钥等受支持的凭据需要单独开启敏感凭据同步。一次性迁移凭据时可以手动导出 `.oxide` 文件，并检查各项包含选项。参阅[云同步配置](cloud-sync-and-backups.md#配置同步)。

## 便携运行时

便携运行时密钥库用于保护导入后的便携凭据。通过应用里的便携运行时或凭据存储页面设置它。如果密钥库处于锁定状态，先解锁再依赖导入的便携凭据。

只有明确要删除本地便携密钥库时，才重置便携运行时。

### 设置便携文件夹

1. 将应用放在可写的文件夹中。macOS 使用 `OxideTerm.app` 所在文件夹，AppImage 使用文件本身所在文件夹，解压运行的程序使用可执行文件所在文件夹。
2. 关闭 OxideTerm，在该文件夹中新建名为 `portable` 的空文件。下次启动时，数据将使用其中的 `data` 子目录。
3. 也可以在该文件夹创建 `portable.json`，指定相对数据目录：

   ```json
   { "enabled": true, "dataDir": "data" }
   ```

   `dataDir` 必须位于便携文件夹内，不能使用绝对路径或包含 `.`、`..` 的路径。`portable.json` 的优先级高于空标记文件。
4. 启动 OxideTerm，按提示设置便携密码或解锁。在“设置 → 常规”确认显示的数据目录和便携状态，再导入便携包。
5. 导入所需的 `.oxide` 数据并试连一台主机。移动便携安装时，先关闭应用，再一起复制程序、标记或配置文件，以及完整的数据目录，包括其中的 `keystore.vault`。

换设备时仍需保留便携密码，当前设备的自动解锁不能替代它。便携模式下的 SSH 配置读取规则见 [OpenSSH 配置](connections-and-forwards.md#openssh-配置)。

## 数据目录备份

在“设置 → 常规 → 数据目录”查看实际位置，或运行 `oxideterm paths --json`。普通安装可能使用自定义目录，便携模式使用上述选定目录。

完整复制目录前，退出 OxideTerm 并停止命令行操作，以便一起保存本地数据库、历史和录制文件。普通安装中的受保护密钥还依赖原系统的凭据存储，单独复制数据目录不足以完成凭据迁移。换设备时，应通过加密 `.oxide` 导出所需凭据；便携配置则需要完整的密钥库和便携密码。

更改数据目录需要重启，不会自动搬移已有文件。先记下原位置，在应用关闭时复制需要的数据，重启后核对所选目录和恢复结果。在确认恢复成功前保留原副本。

## CLI 伴侣工具

自动化、CI 校验或脚本化迁移使用 CLI 伴侣工具：

```sh
oxideterm oxide validate ./profile.oxide
oxideterm oxide preview-import ./profile.oxide --password-stdin --json
oxideterm oxide diff ./profile.oxide --strategy merge --password-env OXIDE_PASSWORD
oxideterm portable status --json
```

便携包密码优先通过标准输入或环境变量提供。不要把密码直接写进 shell 历史。
