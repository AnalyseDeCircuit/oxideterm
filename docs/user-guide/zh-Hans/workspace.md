# 工作区导航

顶栏选择当前查看哪些标签，左侧管理连接，右侧工具辅助当前工作。

## 选择标签范围

顶栏中央的选择器支持搜索，包含以下范围：

| 范围 | 展示内容 |
| --- | --- |
| 全部标签 | 当前窗口的所有标签，默认使用此范围。 |
| 全局页面 | 设置、会话管理、插件、云同步等不绑定具体连接的页面。 |
| 本地终端 | 本地 Shell 标签。 |
| 某个连接 | 该连接的终端、SFTP、IDE、端口转发和绑定连接的插件页面。 |

地址相同但账号、连接身份或路由不同的连接不会合并。选择范围不会连接主机，也不会改变命令的操作对象。

窗口会在本次运行期间记住每个范围上次选中的标签。该标签已关闭时，选择范围内仍存在的标签；范围为空时提供“全部标签”入口，不会自动打开其他主机。范围选择不参与同步，也不跨重启恢复。

筛选只影响展示，隐藏的终端、传输、端口转发和后台任务继续运行。混合分屏标签会出现在各窗格所属的范围中，切换范围不会拆分或隐藏其中的窗格。

## 打开和整理页面

主动打开页面时，会显示对应范围。例如在某个连接范围内打开设置，会切到全局页面；打开某个连接的 IDE，会显示该连接。当前已经是全部标签时，保持全部标签。后台状态更新不会切换范围。

前后切换、数字快捷键和批量关闭都作用于可见标签。拖动排序只改变可见标签的相对顺序，不打乱隐藏标签。标题完整显示，放不下时横向滚动标签栏。关闭页面或将页面移到其他窗口后，各窗口会相应更新选中状态。

## 顶栏与侧边栏

- **命令面板：**点击搜索图标查找操作，无需记住快捷键。
- **禅模式：**隐藏外围导航，专注当前页面；使用已配置的快捷键退出。
- **后台任务：**有后台工作时，可从摘要查看进度。
- **外观：**太阳或月亮表示当前浅色或深色模式。在设置中配置两套方案后，可直接切换。
- **右侧工具：**OxideSens 和各个主机工具在工作区旁打开。经常变化的状态与按需查询的工具分组排列；高度不足时才出现“更多”。
- **应用锁：**完成配置并开启入口后，锁定按钮位于右侧底部。锁定保护工作区，连接继续运行。

全屏时保留顶栏，禅模式隐藏顶栏。Windows 和 Linux 的顶栏操作会为右侧窗口控制按钮留出空间。快捷键提示跟随自定义绑定变化。

主机工具作用于面板中选定的连接，终端操作作用于活动窗格。混合分屏时，应确认实际操作对象，而不是把顶栏范围当成命令目标。

## 快捷命令

快捷命令栏包含可搜索的分组选择器和可横向滚动的命令列表。选定分组后，只展示该组命令；选择会跨重启保留，与命令管理中的筛选互不影响。空分组仍可选择，删除当前分组后返回全部命令。

在命令管理中维护命令、顺序、分组图标和颜色。命令沿用分组颜色，重置自定义颜色可恢复主题默认值。分组及其外观随受支持的导出和云同步数据保存。悬停可查看完整名称和有限长度的命令预览；执行前确认活动终端及广播目标。

分屏操作参见[桌面工作流](desktop.md)，高级命令发送器参见[应用指南](app.md)。
