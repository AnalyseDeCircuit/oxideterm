# 连接与端口转发

日常 SSH 工作优先使用“会话”、“连接池”、“连接监控”、主机工具、图形/VNC 和转发页面。CLI 伴侣工具只用于无界面校验、导出和可重复配置。

## 保存连接

保存连接用于复用 SSH 配置，包括 name、host、user、port、group、tags、color、认证方式和可选连接后命令。

从连接管理器或“会话”视图创建和编辑保存连接。添加新主机时，填写配置，选择认证方式，保存，然后从“会话”打开连接。如果连接失败，编辑同一个保存连接，不要创建一堆标签相近的重复条目。

分组、颜色和标签用于导航。不要把密码、令牌或环境凭据写进名称、分组、标签、备注或连接后命令标签里。

## Kerberos 认证

当组织提供有效的系统登录凭据或票据，且 SSH 服务器支持 Kerberos 时，可使用此认证方式。

1. 新建或编辑 SSH 连接，在认证区域开启“优先使用 Kerberos”。
2. 查看凭据可用性提示。OxideTerm 使用当前操作系统会话的凭据；没有可用凭据时，先按照组织的登录流程获取或更新票据。
3. “Kerberos 服务端身份（可选）”留空时使用 `host/<SSH 主机>`。通过别名或负载均衡地址连接时，填写管理员提供的服务身份，例如 `host/server.example.com`。
4. 选择备用认证方式，并按需配置密码、密钥或 SSH Agent。
5. 保存并连接。认证失败时，结合连接进度检查票据是否有效、服务端身份是否正确，以及服务器是否支持 Kerberos。

“向此服务器委派 Kerberos 凭据”允许远端主机以你的身份访问其他 Kerberos 服务。仅在可信服务器上确实需要此功能时开启。各跳板主机的认证需要分别配置。

## 自动填写动态验证码

1. 打开“设置 → 凭据 → 动态验证码凭据”，点击“添加凭据”。
2. 填写便于识别的名称，输入服务提供的 Base32 密钥或 `otpauth://` 链接。这里填写的是初始化密钥，不是当前显示的六位验证码。
3. 核对算法、6 位或 8 位的位数，以及 1–300 秒的更新周期。导入链接时使用链接中的参数；需要调整时，保存后再次编辑。
4. 检查提示匹配规则，保持凭据启用并保存。
5. 编辑 SSH 连接，在“动态验证码凭据”中选择刚创建的凭据。需要验证码的跳板主机也要分别选择，然后重新连接。

出现匹配的 SSH 认证提示时，OxideTerm 会生成验证码。隐藏输入和可见输入的验证码提示均支持，包括匹配规则覆盖的 JumpServer 提示；其他认证问题仍需分别回答。没有自动填写时，检查凭据是否启用、是否绑定到正确主机，以及规则是否匹配实际提示。验证码被拒绝时，检查本机时间和服务要求的验证码参数。升级应用会保留已有的自定义匹配规则。

编辑凭据时，密钥留空可保留已保存的值。删除前，需要先解除连接和跳板主机对该凭据的绑定。更多检查见[连接与传输排查](troubleshooting.md#连接与传输排查)。

## Mosh 连接

Mosh 适合需要应对短暂网络变化的终端会话。远端需要安装 `mosh-server`，并开放可达的 UDP 端口；OxideTerm 已内置本地客户端。

1. 打开新建连接，选择“Mosh”，填写用于启动远端会话的主机、用户名、SSH 端口和认证信息。
2. 在 Mosh 设置中，将服务端程序保留为 `mosh-server`；如果它不在远端命令搜索路径中，填写其远端路径。
3. UDP 端口或范围留空时自动选择，也可填写 `60001` 这样的端口或 `60000:61000` 这样的范围。在服务器防火墙和网络地址转换配置中放行相应 UDP 端口。
4. UDP 连接需要使用不同的公网主机或地址时，填写 UDP 主机覆盖项。服务器需要时再指定 UTF-8 区域设置。本地预测默认为“自适应”。
5. 需要复用时先保存配置，再打开连接并确认终端可正常输入。

SSH 和跳板主机用于启动远端会话，后续 UDP 连接需要从当前设备直接到达服务器，SSH 跳板不会转发它。每个 Mosh 连接打开一个 UTF-8 终端。需要 SFTP、IDE 或端口转发时，另外打开 SSH 连接。启动成功但终端无法通信时，检查 UDP 主机、所选端口、防火墙和地址族设置。

## 导入连接

### OpenSSH 配置

**设置 → 连接 → 从 SSH 配置导入**会显示正在扫描的配置文件路径。主机发现、别名解析和自动同步使用同一路径。便携模式优先读取 `<数据目录>/.ssh/config`；该文件不存在时读取当前用户的 `~/.ssh/config`。便携配置文件为空时，主机列表也保持为空。便携模式的默认私钥发现、导入密钥及 `known_hosts` 仍使用便携数据目录。

### 其他客户端

打开“设置”，进入“连接”，使用“从其他客户端导入”。选择来源及对应文件或文件夹，检查预览后导入所选连接。遇到同名连接时可以跳过或重命名，也可以用可选目标分组覆盖来源分组。

支持的来源和输入：

| 来源 | 输入 |
|------|------|
| SecureCRT | 会话 `.ini` 文件、Sessions 文件夹或 SecureCRT `.xml` 导出文件 |
| Xshell | `.xsh` 文件、Sessions 文件夹或 `.xts` 归档 |
| Termius | 导出的 JSON |
| MobaXterm | `.mxtsessions` 导出文件 |
| WindTerm | `user.sessions` JSON |
| Electerm | 包含 `bookmarkGroups` 和 `bookmarks` 的书签 JSON，或旧式书签数组 |
| FinalShell | `conn` 文件夹，或包含 `conn` 的 FinalShell 数据文件夹 |

OxideTerm 会导入名称、分组、主机、端口、用户名以及受支持的密钥文件路径等安全连接元数据。密码、口令、内嵌私钥、证书、代理凭据及其他敏感值不会被导入。不受支持的代理、跳板机和端口转发设置会作为预览警告显示。完成元数据导入后，请在 OxideTerm 中配置认证并复核这些高级设置。

## 连接运行时

保存配置和在线运行时节点不是同一个东西：

- 保存配置：OxideTerm 应该使用的主机和连接设置。
- SSH 节点：某个主机当前在线或正在重连的运行时状态。
- 终端会话：附着到 SSH 节点的可见 shell。
- SFTP 会话：附着到 SSH 节点的文件浏览或传输页面。
- 主机工具快照：通过所属 SSH 节点采样得到的资源视图。
- 图形/VNC 会话：由保存的 RDP/VNC 配置或节点拥有的图形运行时提供的查看器。

当终端像是卡住、SFTP 读不了目录、主机工具看起来过期、图形/VNC 查看器断开或重连行为不清楚时，优先看连接池和连接监控。从应用状态里重连运行时；不要为了重连而删除并重建保存连接。

## 连接流程

典型流程：

1. 打开“会话”。
2. 选择一个保存连接，或创建新连接。
3. 打开连接。
4. 等 SSH 节点和终端标签页变为在线。
5. 需要时，从同一个已连接节点打开 SFTP、IDE、主机工具或转发，或者打开保存的 RDP/VNC 配置。

对不稳定主机做测试时，保持连接监控可见。它会显示节点是已连接、正在连接、已失效还是不可用。

## 主机工具

主机工具是节点级远端环境检查页面，适合查看进程、Docker、服务、tmux、软件包、日志、端口、文件系统、计划任务和指标。

资源快照可能独立于终端标签页变旧。重试动作前，先刷新主机工具页面或重连所属节点。主机工具动作应保持显式且可检查，不要把它当作隐藏后台清理工具。

## 图形与 VNC

图形/VNC 会话是由保存的 RDP/VNC 配置或已连接节点的图形运行时提供的视觉应用页面。远端工作流需要桌面或图形应用，而不是终端输出时使用它。

查看器状态与终端 scrollback 分离。如果配置驱动的查看器断开，重连其 provider/helper；如果节点启动的查看器断开，从节点上下文重连或重启图形会话。不要为了修复查看器而复制保存 SSH 配置。

## 串口终端

串口终端是本地设备传输，不是 SSH 子功能。它适用于 USB-UART 适配器、开发板、路由器控制台、交换机控制台或其他本地串口设备。

在新建连接弹窗中选择 `Serial` 分支即可打开串口终端。填写 `Serial port`、`Baud rate`、`Data bits`、`Stop bits`、`Parity` 和 `Flow control`，然后选择 `Open Serial`。命令面板也提供 `Open Serial Terminal`。

常见端口名：

| 平台 | 示例 |
|------|------|
| macOS | `/dev/cu.usbserial-0001`、`/dev/cu.usbmodem*` |
| Linux | `/dev/ttyUSB0`、`/dev/ttyACM0` |
| Windows | `COM3`、`COM10` |

需要复用同一组设备参数时，使用 `Save serial profile` 和 `Profile name`。保存的串口配置和保存的 SSH 连接是分离的。

串口终端不提供 SFTP、端口转发、ProxyJump、SSH 主机密钥校验、SSH Agent、远程 IDE 或 SSH 连接池行为。串口分屏被禁用，因为串口设备通常是独占写入资源。

## 端口转发

使用转发页面创建和管理本地、远端和动态转发。

转发类型：

- Local：本地端口通过 SSH 连接到远端目标。
- Remote：远端端口反连到本地目标。
- Dynamic：SOCKS 风格隧道。

把转发附着到所属连接上，这样生命周期才清楚。只有当转发应随连接打开而启动时才启用自动启动。测试新转发时，同时确认转发行和所属连接都是健康的。

## 校验与导出

使用应用检查可见连接和转发状态。CI、可审查导出或支持流程再使用 CLI 伴侣工具：

```sh
oxideterm connections validate --strict
oxideterm connections export --format raw-safe --json
oxideterm forwards validate --json
```

`raw-safe` 输出用于审查和自动化，不包含凭据值。
