# 应用指南

这份指南介绍 OxideTerm 桌面应用本身。日常终端、SSH、文件、转发、主机工具、图形/VNC、AI、插件、同步和设置工作都从桌面应用开始。`oxideterm` CLI 是单独的伴侣工具，用于自动化、诊断、CI、迁移和恢复。

## 首次启动

从系统启动器打开 OxideTerm。第一次使用时，建议先打开一个本地终端标签页，再添加远端主机。本地终端可以先确认当前机器上的渲染、键盘输入、shell 启动、字体和主题设置都正常。

推荐的首次流程：

1. 打开一个本地终端。
2. 输入简单命令，例如 `pwd` 或 `echo ok`。
3. 打开设置，检查终端字体、主题、shell 和 AI 设置。
4. 添加一个保存的 SSH 连接。
5. 连接主机，并验证终端输入、文件浏览、主机工具和连接状态。

## 应用布局

主窗口围绕带标签页的工作区组织，左侧是活动栏和上下文侧边面板。

主要区域包括：

- 会话：保存的连接、活跃 SSH 节点和终端会话。
- 连接池：可复用的连接运行时状态。
- 连接监控与主机工具：健康状态、重连状态、进程、Docker、服务、tmux、软件包、日志、端口、文件系统和指标。
- 连接矩阵：更完整的连接概览。
- 文件管理器与 SFTP：浏览、预览、上传、下载和编辑远端文件。
- 图形/VNC：打开保存的 RDP/VNC 配置，或在已连接 SSH 节点提供能力时打开节点启动的图形会话。
- 插件：安装、启用、禁用和配置插件。
- 云同步：同步应用状态并查看同步状态。
- 通知：查看应用事件和警告。
- 设置：配置应用行为。

标签页是主要工作面。一个标签页可以是本地终端、SSH 终端、SFTP、IDE 工作区、图形/VNC、设置页、文件管理器、插件管理器、连接监控或其他应用页面。

## 标签页与面板

用标签页分隔不同任务。同一个任务需要多个 shell 并排工作时，在终端标签页里使用分屏面板。

终端状态属于具体面板。关闭面板会关闭可见终端，但不等于删除保存的连接配置。远端工作中，连接运行时状态和可见终端标签页是分开管理的。

典型终端流程：

1. 打开或选择一个保存连接。
2. 启动 SSH 终端。
3. 需要时拆分终端面板。
4. 通过命令标记和 shell 历史跟踪输出。
5. 长时间任务或不稳定连接，保持连接监控可见。

终端相邻辅助能力始终绑定到活跃终端面板：

- 使用终端右键菜单或命令栏处理复制、粘贴、搜索、命令选择和显式传输动作。
- 终端背景图片从设置里配置；背景是视觉状态，不是终端 scrollback。
- 远端执行 `rz`、`sz`、`rx` 或 `rb` 等真实传输命令后，如果出现 X/Y/ZMODEM 提示，选择本地文件或目录，并从可见提示/通知查看进度。
- 提权凭据从设置里管理。不要把 sudo/su 密码写进连接名称、备注、快捷命令、AI 提示词、日志或支持包。

### 高级命令发送器

当需要按计划向一个或多个终端面板发送相同输入时，使用高级命令发送器。它支持文本或十六进制输入、按行或按字符发送、重复次数，以及当前面板、全部面板或明确选择的目标。

任务开始时，发送器会冻结目标面板。切换标签页或打开新面板不会扩大运行中的任务；已关闭的目标会被跳过，不会被替换或自动重连。隐藏发送器面板不会取消任务，需要时请显式停止。进度表示本地终端输入路径已接受数据，不代表远端程序已经执行或确认命令。

## 保存连接

经常复用的主机应该保存为连接。保存连接可以包含：

- 名称、host、port 和 username。
- 用于导航的 group、color 和 tags。
- 认证方式，例如 SSH agent、密钥、密码或默认 SSH 行为。
- 可选的连接行为，例如连接后命令。
- 在配置支持时使用代理或跳板机。

分组和标签只用于导航。不要把密码、令牌或凭据写进名称、分组、标签或备注。

## 连接主机

在“会话”区域选择保存连接并打开。连接成功后，应用会为 SSH 节点创建运行时状态，并打开终端。

如果主机断开，通过连接池或连接监控判断运行时是正在重连、已失效还是不可用。应从应用状态里重连，不要为了重连而重新创建保存连接。

主机工具属于已连接节点。图形/VNC 会话也可能属于保存的 RDP/VNC 配置；节点启动的图形会话则由 SSH 节点拥有运行时。打开或关闭这些页面不应重写保存配置；状态过期时，应通过所属配置或节点刷新。

## SFTP 与远端文件

使用 SFTP 或文件管理器处理远端文件：

- 浏览远端目录。
- 下载或编辑前先预览文件。
- 上传和下载文件。
- 启动大文件传输并跟踪进度。
- 连接不稳定时，重连后再重试传输。

“文件传输”设置默认为**自动**：SFTP 仍负责浏览并作为首选传输协议；只有已连接的 POSIX 主机无法打开 SFTP 子系统时，才回退到传统 SCP。也可以强制选择 SFTP 或 SCP 做兼容性测试。SCP 在当前通道在线时可以暂停和继续，但传统 SCP 没有按偏移恢复协议，因此断线后的重试会从头开始。

终端原生 modem 传输和 SFTP 是两条路径。远端程序需要通过当前终端通道交换 X/Y/ZMODEM 协议字节时，才使用 modem 传输。

覆盖重要远端文件前，先确认路径并保留备份。远端写入就是目标系统上的真实写入。

## IDE 工作区

需要项目式远端文件工作流时，使用 IDE 页面。为已连接节点打开 IDE 工作区，选择远端目录，然后在编辑器标签页中处理项目文件。

IDE 工作区状态和普通终端标签页不同。当前编辑器标签页、项目根目录、未保存缓冲区和打开文件都属于 IDE 页面。连接中断后，应先重连，再依赖保存或项目搜索结果。

## 端口转发

使用转发界面管理本地、远端和动态转发：

- 本地转发：本地端口连接到远端目标。
- 远端转发：远端端口反连到本地目标。
- 动态转发：创建 SOCKS 风格隧道。

只有当转发应随所属连接自动启动时才启用自动启动。测试新转发时建议保持连接监控可见。

## 主机工具与图形

需要查看进程、容器、服务、tmux、软件包、日志、端口、文件系统、计划任务或主机指标时，从已连接节点上下文打开主机工具。会改变主机状态的动作应先经过应用确认流程。

图形/VNC 会话用于远端视觉工作流。查看器可能由保存的 RDP/VNC 配置及其 helper 进程提供，也可能由节点拥有的图形运行时提供；渲染帧不是终端输出，关闭查看器也不等于删除保存配置。

## AI 侧边栏

AI 侧边栏会结合当前应用上下文工作。启用工具调用后，它可以检查目标、使用终端和文件工具，并对当前工作区状态做总结或操作。

如果当前供应商和模型支持推理控制，聊天界面会显示按供应商适配的“思考力度”菜单。已知模型会依据能力数据规范化；已知供应商的未知模型使用该供应商的请求格式，未知供应商才会被视为不支持。ACP session 使用自己的 session 选项，不使用原生供应商的推理字段。

推荐 AI 使用流程：

1. 先打开相关终端、连接、SFTP、IDE 或设置页面。
2. 只在需要时包含上下文。
3. 让 AI 先列出或选择明确目标，再运行命令。
4. 对写入、交互式或破坏性操作，认真检查审批提示。
5. 接受后续修改前，先看工具结果。

不要把凭据粘贴进 AI 提示词。API key 或凭据应使用应用里的供应商密钥和凭据存储页面。

### Agent Skills

OxideSens 可以从工作区、用户数据目录和已启用的 Native 插件中发现受限的 `SKILL.md` 工作流。在“设置 → OxideSens → 工具 → Agent Skills”中查看已发现的技能、启用或禁用单个技能，并刷新目录。加载技能只会提供说明，不会授予终端、文件、凭据或网络权限；后续动作仍必须经过现有工具策略和批准模式。发现顺序与资源限制见 [Agent Skills 参考](../../agent-skills.md)。

## 外部 MCP 客户端

外部编辑器、命令行 AI 或其他 MCP 客户端可以通过 OxideTerm 使用已保存的 SSH 连接排查服务器问题。打开“设置 → 网络与代理 → 外部 MCP 控制”，然后：

1. 创建普通模式或完全权限模式客户端。普通模式的高风险操作需要在 OxideTerm 内批准；完全权限模式对已勾选工具组跳过逐项批准。
2. 复制回环 HTTP 端点和只显示一次的客户端凭据。
   监听端口默认为 `0`，由应用自动选择；需要固定端口时可输入 `1` 至 `65535` 并应用。端口偏好只保存在当前设备，不进入普通设置、`.oxide` 导出或云同步。
3. 在外部 MCP 客户端中把端点配置为 Streamable HTTP URL，并添加 `Authorization: Bearer <凭据>` 请求头。
   如果客户端只支持 stdio，把命令设为 `oxideterm mcp bridge`，并通过客户端的秘密环境配置提供 `OXIDETERM_MCP_TOKEN=<凭据>`；bridge 会自动发现当前回环端点。不要把凭据放进命令参数。

   CC Switch 及接受 `command`、`args`、`env` 对象的客户端可以直接使用应用中“复制 stdio JSON”生成的配置：

   ```json
   {
     "command": "oxideterm",
     "args": ["mcp", "bridge"],
     "env": {
       "OXIDETERM_MCP_TOKEN": "<客户端凭据>"
     }
   }
   ```

   如果客户端要求顶层 `mcpServers`，将同一个对象包装为：

   ```json
   {
     "mcpServers": {
       "oxideterm": {
         "command": "oxideterm",
         "args": ["mcp", "bridge"],
         "env": {
           "OXIDETERM_MCP_TOKEN": "<客户端凭据>"
         }
       }
     }
   }
   ```

   两种 JSON 都包含客户端凭据，只能保存到受信任客户端的秘密配置中，不要写入项目文件、日志或公开内容。运行前需在“设置 → 常规”安装命令行工具，并保持 OxideTerm 运行。
4. 让客户端先调用 `connections_browse`，再按需读取连接详情。连接管理组可创建、修改或删除 SSH、Mosh、Telnet、串口、RDP 和 VNC 配置；凭据管理组只能写入新值、查看存在性或遗忘指定槽位，不能读取既有秘密。
5. 普通模式下，在 OxideTerm 的“待批准操作”中检查实际客户端、目标和命令；批准后，客户端调用 `mcp_commit_action`。完全权限模式直接执行。
6. 使用返回的 `command_ref` 查询状态并分段读取标准输出和标准错误。

当前实现已经开放连接与凭据管理、NodeRouter 节点租约、终端与录制、RDP/VNC、SSH exec、有界临时 artifact、SFTP 与后台单文件传输、远端 IDE 工作区、转发、快速命令、插件生命周期、云同步、当前客户端自己的脱敏 MCP 审计记录，以及类型化 Host Tools 快照和操作。后台传输只在授权 SFTP 根与客户端私有 artifact 之间移动数据，不接受本机路径；当前最大 64 MiB，尚不支持跨请求断点恢复。IDE 工作区必须从已授权的 SFTP 文件会话挂载，读取与结构化编辑可分别开启；文本读取上限为 4 MiB，编辑必须使用先前读取到的 revision，关闭工作区只释放它自己的 IDE consumer。云同步先返回一次性预览计划，应用前会重新核对本地与远端版本；远端发布不提供虚假撤销，含 SSH、Mosh 或凭据的拉取也只保留产品已有的加密恢复备份。Host Tools 只接受固定资源与动作 schema，不提供自由 shell 或插件调用入口。释放 MCP 节点租约不会断开仍由其他终端、SFTP、IDE 或转发消费者使用的物理 SSH 节点；只有明确批准的 `nodes_disconnect` 才会断开节点。

后台命令和 SFTP 传输除各自的领域句柄外还返回 `operation_ref`。`mcp_operation` 可读取统一的脱敏状态与进度，`mcp_cancel_operation` 可请求取消；取消命令或上传并不代表已经撤销远端副作用。

只有工具结果明确返回 `undo_ref` 时才可撤销。`mcp_revert` 目前复用云同步本地应用的严格恢复逻辑，仍要求云同步工具组与原有 revision 检查；远端发布、命令、上传和永久删除不会获得虚假撤销句柄。

客户端凭据在 OxideTerm 侧只保存摘要。停用或撤销客户端会立即取消其命令、待批准操作和节点租约。端点、授权记录和凭据都不会进入普通设置、`.oxide` 导出或云同步。stdio bridge 的环境变量由外部客户端进程负责保护；OxideTerm 不会把它写回配置文件。

完全权限模式不等于开放全部工具。每个客户端仍需在设置中单独勾选连接、节点、命令、审计和临时内容等工具组；未勾选工具不会发布，也不能调用。客户端也可用 `mcp_request_access` 发起授权请求，但即使处于完全权限模式也必须在应用内批准；用 `mcp_revoke_access` 主动关闭工具组则立即生效并撤销对应句柄。Bearer 认证、应用锁、秘密不可读取边界和审计在两种模式下始终生效。

## 设置

交互式配置优先使用设置页面：

- 通用应用行为。
- 外观、主题和整个窗口的透明度。
- 终端 renderer、shell、字体、编码、背景图片、传输辅助和本地终端行为。
- 提权凭据及其提示/作用域设置。
- SSH、重连、SFTP 和 IDE 行为。
- AI 供应商、模型选择、记忆、工具调用和知识库设置。
- 快捷键、帮助和更新信息。

探索性或视觉类修改优先用桌面 UI。只有需要脚本化或跨环境重复执行时才使用 CLI。

## 插件

使用插件管理器安装、启用、禁用、更新和配置插件。启用非本人编写的插件前，先查看插件权限和设置。

插件设置和插件凭据应通过专门的应用页面管理。不要把凭据写进插件名称、标签或普通文本字段，除非该字段明确是凭据字段。

## 云同步与备份

需要查看同步状态、手动同步或处理可见同步问题时，使用桌面应用里的云同步页面。执行高影响导入、恢复或同步变更前，保持备份可用。

需要支持包或自动化恢复计划时，在桌面应用中确认问题后再使用 CLI 伴侣工具。

## CLI 伴侣工具

CLI 伴侣工具适合无界面、可重复或诊断类工作：

- `doctor` 和支持报告。
- 脚本化设置变更。
- 无界面连接校验。
- 备份、恢复和云同步自动化。
- CI 中检查导出的配置。

日常使用先从桌面应用开始。CLI 应辅助桌面工作流，而不是替代桌面应用。
