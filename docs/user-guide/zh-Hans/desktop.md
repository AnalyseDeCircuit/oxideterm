# 桌面工作流

## 首次启动

打开 OxideTerm 后，先看左侧活动栏。主要区域包括会话、连接池、连接监控、主机工具、图形/VNC、插件、云同步、文件管理器、通知和设置。

如果当前没有会话，建议先创建一个本地 shell 标签页。这可以先确认终端渲染、shell 集成、输入处理和主题设置都正常，再去添加远端主机。

## 活动栏

活动栏是进入应用各个页面的入口：

- 会话：创建、打开、分组和监控 SSH 工作。
- 文件管理器与 SFTP：浏览文件并管理传输。
- 连接池、连接监控和主机工具：查看连接运行时状态、资源快照、进程、容器、服务、tmux、日志、端口和指标。
- 图形/VNC：打开保存的 RDP/VNC 配置，或打开从已连接节点启动的视觉会话。
- 插件：管理已安装插件和插件设置。
- 云同步：查看同步状态并执行同步操作。
- 通知与审计：查看通知、操作记录、会话历史和终端输出录制。
- 设置：修改应用行为和供应商配置。

当某个流程变得不清楚时，先回到“会话”或“连接监控”。这些页面能看到主机是已保存、正在连接、已连接、已失效还是不可用。

## 终端面板

终端标签页可以用于本地 shell 和 SSH 会话。一个任务需要多个 shell 时，使用分屏面板。命令标记、shell 集成和终端历史属于具体面板；关闭面板不应该等同于断开保存的 SSH 主机。

### 在一个标签内组合页面

例如，上传文件时把终端和 SFTP 并排放置：

1. 分别打开终端和 SFTP 标签页。
2. 将 SFTP 标签拖入终端内容区，移到左、右、上或下边缘，在出现布局预览的位置松开。
3. 拖动分隔线调整两个页面的大小，单击窗格内部可将其激活。
4. 想拆出页面时，使用窗格标题栏的“移至新标签”，也可以通过标题栏将它移到新窗口。
5. 不再需要某页时，使用该窗格的关闭操作；若出现未保存内容或运行中进程的提示，先处理提示。只剩一个页面后，额外的窗格标题栏会隐藏，主标签显示该页面的名称。

每个组合最多四个窗格。终端、SFTP、IDE、端口转发、笔记、设置、云同步、审计、远程桌面和插件页面均可组合。再次打开设置这类单实例页面时，会定位到原窗格。将整个组合移到新窗口，会保留现有会话和布局。

对于长时间运行的任务，保留连接池或连接监控里的状态可见。重连行为跟连接运行时状态相关，不只取决于当前有没有可见终端标签页。

常见面板组织方式：

- 无关任务使用不同标签页。
- 需要并排比较的命令使用分屏面板。
- 一个面板持续看日志，另一个面板执行编辑或部署步骤。
- 只关闭不再需要的面板或标签页，不要误删保存连接配置。

终端右键菜单和命令栏用于明确的面板动作，例如复制、粘贴、搜索、命令选择和终端原生文件传输。背景图片和终端图像 placement 是视觉/渲染状态；如果全屏 TUI 退出后留下旧图像内容，优先清屏或重新打开面板，不要修改保存连接数据。

### 自由输入模式

在“设置 → 终端 → 自由输入模式”中启用后，可用鼠标编辑当前普通 Shell 命令：

- 在当前命令内单击，移动远端行编辑器的光标。
- 选择命令文本后，按 Backspace/Delete、直接输入、粘贴，或使用复制/剪切快捷键即可编辑选区。
- 在匹配的 `()`、`[]` 或 `{}` 内双击，选择最内层括号中的内容。
- 拖动已选命令文本可移动选区；按住 Ctrl 拖动则复制选区。
- 拖动历史输出中的单行文本，会在目标命令位置插入副本。
- 按住 Alt 拖动选中文本，用它替换当前命令。

macOS 可按 Command+Shift+F，Windows 和 Linux 可按 Ctrl+Alt+F 切换此模式。该动作也已加入命令面板，并可在“设置 → 快捷键”中重新绑定。

当自由输入模式确认当前处于普通命令输入区时，macOS 的 Command+C/X/V 与 Windows、Linux 的 Ctrl+C/X/V 会执行编辑器式的复制、剪切和粘贴。可配置的终端动作在 Windows、Linux 上还默认使用 Ctrl+Shift+C/X/V。目标不属于可确认的命令输入或选区时，原有终端按键语义保持不变。

OxideTerm 只发送终端按键和文本序列，远端 Shell 或编辑器始终是状态的唯一来源。全屏和鼠标追踪程序继续自行处理鼠标输入。Vim、Neovim 和 Emacs 可以通过 OxideTerm 的显式适配器上报当前模式和选区；通过验证后，复制、剪切和粘贴快捷键才能作用于编辑器选区，同时不会放宽备用屏幕和鼠标追踪保护。

OxideTerm 不会修改编辑器启动文件。Vim 或使用 `init.vim` 的 Neovim 可在配置中加入：

```vim
if exists('$OXIDETERM_VIM_INTEGRATION') && filereadable($OXIDETERM_VIM_INTEGRATION)
  execute 'source ' . fnameescape($OXIDETERM_VIM_INTEGRATION)
endif
```

使用 `init.lua` 的 Neovim 可加入：

```lua
local adapter = vim.env.OXIDETERM_VIM_INTEGRATION
if adapter and vim.fn.filereadable(adapter) == 1 then
  vim.cmd("source " .. vim.fn.fnameescape(adapter))
end
```

Emacs 可在启动文件中加入：

```elisp
(when-let ((adapter (getenv "OXIDETERM_EMACS_INTEGRATION")))
  (when (file-readable-p adapter)
    (load adapter nil t)
    (oxideterm-free-type-mode 1)))
```

本地终端会自动提供这些适配器路径。SSH 会话需要先在“设置 → 终端 → 感知与集成”中安装或修复远程 Shell 集成；适配器会安装到 `~/.oxideterm/shell-integration`。只有 SSH 服务器接受 OxideTerm 针对当前通道发送的能力标记时，Shell 才会导出这些路径。限制严格的服务器仍可通过标准 OSC 7 获得目录感知，但会停用私有编辑器增强。已加载的适配器会在 tmux、GNU screen 和 Zellij 中抑制私有消息，因为共享窗格无法按附加客户端隔离这些消息。启用后的适配器只上报编辑器身份、模式、选区形态和能力，以及用户明确请求复制或剪切的选区内容。剪贴板响应有长度限制，而且只有与最近一次用户快捷键请求匹配时才会被接受。

### 退格键与删除键兼容性

“设置 → 终端”中可以分别选择物理退格键和删除键发送的序列。默认情况下，退格键发送 `DEL (0x7F)`，删除键发送 `CSI 3~`。只有传统 Shell、串口设备或远端程序要求 `Ctrl+H (0x08)` 等其他序列时才需要修改。使用 Kitty 键盘协议的会话仍遵循协议规定的按键编码。

### 粘贴前编辑

1. 复制文本，在目标终端内右键选择“粘贴前编辑”。多行粘贴确认框也提供“编辑”入口。
2. 在弹窗中修改文本，可以增删行，也可以使用“撤销”和“重做”。
3. 如果复制了 Markdown 代码块，点击“移除代码块标记”去掉外层标记。普通粘贴会保留复制时的文本，只有点击此按钮才会处理代码块标记。
4. 检查目标终端和最终文本，然后点击“粘贴”；点击“取消”则关闭弹窗，不发送草稿。

文本中的换行会一起发送，接收它的 Shell 可能据此执行命令。点击“粘贴”前，编辑内容只保留在本地弹窗中。

## 保存连接

经常复用的主机应该保存为连接。连接配置包含 host、user、port、group、color、tags、认证方式和可选的连接后命令。可以的话优先使用 SSH agent 或密钥认证。

分组用于导航和批量整理，不要把凭据或环境密码编码进分组名。

保存连接后，从“会话”视图打开它。如果连接失败，编辑原保存连接，不要创建一堆主机或标签几乎相同的重复连接。

## 连接运行时视图

连接池和连接监控显示实时运行时状态。终端像是卡住、SFTP 无法读取目录、转发无响应或需要检查重连行为时，优先看这些页面。

运行时状态和保存配置回答的是不同问题：

- 保存配置：OxideTerm 应该连接哪个主机？
- 运行时节点：这个主机当前是否连接或正在重连？
- 终端会话：哪个可见 shell 附着在运行时上？
- SFTP 会话：文件浏览是否正在使用在线传输？
- 主机工具快照：最近一次资源采样观察到了什么？
- 图形/VNC 会话：查看器是否连接到所属的保存配置/helper 或节点拥有的在线会话？

主机工具适合只读式主机检查。会破坏或改变主机状态的动作应保持显式，并在执行前检查应用确认输出。

## 文件管理器与 SFTP

文件管理器用于远端浏览、上传、下载、预览和基础文件操作。远端编辑就是实际远端写入：关键文件先备份，覆盖前确认路径。

连接不稳定时，先暂停大文件传输，重连后再重试。保存连接状态和传输状态是分开的；传输失败不应该要求删除连接。

### 通过终端传输文件

在 SSH 终端中运行远端传输程序，OxideTerm 识别传输请求后，会打开本地文件或保存位置选择框。

| 操作 | 远端命令 | 本地选择 |
| --- | --- | --- |
| 使用 trzsz 上传 | `trz` | 选择本地文件 |
| 使用 trzsz 下载 | `tsz report.txt` | 选择保存目录 |
| 使用 ZMODEM 上传 | `rz` | 选择本地文件 |
| 使用 ZMODEM 下载 | `sz report.txt` | 选择保存目录 |

远端需要安装相应程序。下载时若要覆盖本地同名文件，运行 `tsz -y report.txt` 或 `sz -y report.txt`；未请求覆盖时，同名文件会重命名保存。接收替换文件期间，原文件会保留：trzsz 校验成功后保存替换文件，ZMODEM 则在整批传输成功后替换。取消传输会保留原文件。

串口设备使用终端控制栏的“二进制传输”，选择对应的 XMODEM、YMODEM 或 ZMODEM 上传、接收操作。先让设备进入相应的传输模式；XMODEM 接收还需要指定保存文件名，因为协议不携带文件名。

需要浏览目录或管理传输队列时使用 SFTP。终端传输未启动时，参阅[连接与传输排查](troubleshooting.md#连接与传输排查)。

## 审计与会话录制

从活动栏打开“通知与审计”。通知用于查看近期消息；“审计”“会话”和“会话录制”用于查看操作历史和回放。

### 开启并查找操作记录

1. 进入“审计”，打开“启用审计”。默认关闭，开启后开始记录后续操作。
2. 执行需要检查的连接、命令、文件或转发操作，再返回点击“刷新”。
3. 选择时间范围及其他筛选条件，输入搜索内容后按回车确认。
4. 打开记录，查看目标、来源、结果和结果依据。“已发送”表示输入已发出；退出码或协议响应能进一步说明操作是否完成。
5. 进入“会话”查找同一会话的关联操作，再打开其操作历史或录制。

关闭审计后停止采集新记录，已有记录仍可查看。可以在页面的设置区域调整保留时间和容量，然后点击“保存”。

### 录制并回放终端输出

1. 保持审计开启，进入“会话录制”，打开“记录终端输出”。
2. 阅读并确认录制提示。之后本地终端、SSH、Telnet、Mosh 和串口会话显示的输出会被记录。
3. 返回会话录制，刷新列表并打开一条录制，使用播放、暂停、进度定位、倍速或从头播放查看内容。
4. 不再需要采集时，关闭“记录终端输出”；停用审计也会停止新的输出录制。

录制包含显示的输出和终端尺寸变化，不包含键盘输入和终端文件传输载荷；Shell 或程序回显的文字仍可能出现在输出中。录制在本机加密保存，不参与云同步。出现内容不完整或过期提示时，表示部分输出已无法回放。

| 数据 | 默认保留时间 | 默认保留容量 |
| --- | --- | --- |
| 操作记录 | 90 天 | 512 MiB |
| 终端输出 | 7 天 | 2 GiB |

两个开关初始均为关闭。保留时间可设为 1–3650 天，容量可设为 1–65536 MiB；在对应的“审计”或“会话录制”页面修改后保存。

### 导出记录

按照当前筛选条件，选择“导出摘要为 JSON”或“导出摘要为 CSV”。“导出受保护详情”需要确认，会将命令、路径、端点、账号和操作详情保存为明文文件，不包含会话录制。分享前请检查文件内容；清除记录或缩短保留时间前，先导出需要保留的记录。

## IDE 工作区

IDE 工作区适合项目式远端编辑。先从已连接节点打开 IDE，选择远端目录，然后在 IDE 页面里的文件标签页中工作。

保存重要修改前，确认连接仍然健康。未保存编辑器缓冲区属于 IDE 工作区；关闭 IDE 标签页前，应先保存、丢弃或明确保留这些修改。

## AI 侧边栏

当当前终端、连接、文件或设置上下文很重要时，使用 AI 侧边栏。提问前保持相关标签页打开。启用工具调用后，对写入、终端输入和危险命令的审批提示要逐条检查。

执行命令时，最好让 AI 指定明确的保存连接、SSH 节点、终端会话、SFTP 会话或 IDE 工作区。不要让它从命令文本里猜主机。

## 设置

设置按功能区组织。外观、终端行为、AI 供应商、云同步、便携运行时、帮助与关于等交互式配置优先用桌面界面修改。

脚本化或可重复的修改使用 CLI，并先加 `--dry-run`。CLI 和桌面应用读取同一套配置文件。

## 命令面板与导航

日常导航使用标签页和活动栏。知道动作名称但不想离开键盘时，使用命令面板。

如果某个页面打开到了错误上下文，回到“会话”视图，选择正确连接或标签页，然后再从那里打开目标页面。

提权提示或 modem 传输这类上下文敏感辅助动作，需要先激活目标终端面板。辅助动作应作用于活跃面板/session，而不是从 prompt 文本、标签标题或保存主机标签反推目标。

## 更新

在“设置 → 帮助与关于”里查看当前版本和更新通道。稳定版和测试版使用独立更新通道，应该选择与当前安装包匹配的通道。
