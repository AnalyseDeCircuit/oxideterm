# Contributing to OxideTerm

OxideTerm is developed and maintained solely by a single engineer. The author currently has no intention of profiting from this project, and has not received any revenue from it — no subscriptions, no paid tiers, no ads, no sponsors, no donations. This is a personal project built with love and caffeine.

### Code Contributions
Before starting a substantial change, open an issue to discuss the problem, intended behavior, and implementation direction. Small, focused fixes may be proposed directly. Changes are evaluated based on project direction, maintainability, cross-platform behavior, and the long-term cost of supporting them, so not every proposal will be merged.

Features that do not need changes to the core application may be a better fit for a plugin. OxideTerm supports sandboxed WASM plugins with capability-gated host APIs. If a required plugin API is missing, feel free to open an issue to discuss the interface.

### Issues & Feature Ideas
Bug reports and feature suggestions are always welcome via GitHub Issues. I do my best to read and respond to every one.

> **Note on Ideas:** The maintainer may independently implement suggestions submitted via issues. Submitting an idea or proposal does not create joint authorship, shared copyright, or intellectual property rights over any subsequent implementation.
