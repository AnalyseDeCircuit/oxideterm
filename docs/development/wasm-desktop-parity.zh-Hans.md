# WASM 工作台与桌面端逐项差异审计

**2026-11-27 · 基准：[main@4b7ada080](https://github.com/AnalyseDeCircuit/oxideterm/tree/4b7ada080fd8ba54ee00e8b549a70514e35eb240)。** 按源码对照桌面 GPUI、浏览器 Demo、浏览器 WSS 网关三条路径，包括已合并的动态发现 #872。本文是差异清单，不是已经修复的功能清单。外观结论指代码明确规定的布局、字体、内容、状态和绘制分支，不把没有截图测量的像素偏差写成事实。

**已完成的改动以 ☑ 标记。** BLE 输入不再改投网关，SFTP 按端点建页；云同步预览和知识库索引不再显示虚假的成功结果。

### 怎么读

☑ 已按该条的处理范围修复；☐ 待处理或仅完成一部分。勾选 Web Demo 的行为不代表网关已有对应服务。

- **对齐**：浏览器具备实现条件，应与桌面使用同一视图或同一交互合同。
- **接服务**：界面可以共享，数据、授权或副作用需要网关、浏览器 API 或持久化适配。没有相应能力时不展示执行入口。
- **演示**：只改变本页示例数据。允许在明确标记的 Demo 中展示；不能报成真实远端成功。
- **原生隐藏**：只有桌面宿主才能兑现的原操作。仅隐藏该操作，不连带隐藏整页。详见末节。
- 页级入口见[工作区标签枚举](../../crates/oxideterm-workspace/src/lib.rs)、[桌面内容路由](../../crates/oxideterm-gpui-app/src/workspace/tabs/detach.rs)、[Web 工作台](../../crates/oxideterm-gpui-web/src/host.rs)。[附录](wasm-desktop-parity-inventory.zh-Hans.md)按源码枚举列出标签、设置分区和快捷键入口，防止只审到默认首屏。

## 10. 先改什么，怎样算对齐

1. **先拦错目标和假成功。** BLE 和 SFTP 见 C04、C09、C13–C14、F07、F15。云同步在真实服务就绪前只提供配置预览（P04–P05），知识库的嵌入状态按实际数据呈现（A09）。
2. **先对齐每天用的壳，再接新服务。** 按 W02、T01–T09、T15–T16 把最近连接、标签重命名/右键/关闭、两个方向的分屏、键盘和输入法对齐。验收用同一组保存连接、同一套标签和同一焦点状态，分别从鼠标、快捷键、命令面板进入；结果应是同一对象和同一操作。欢迎页再按相同的侧栏、主题和背景状态对齐颜色及折行。
3. **后续按工作流接网关。** 先做到“选连接 → 打开终端 → 打开该节点 SFTP → 编辑、保存 → 关终端后 SFTP 仍可用”，再补 RDP/VNC、监控、同步等独立服务。只有收到相应服务的成功结果，才更新远端状态；Demo 的内存操作仍可作为演示。

## 11. 只在浏览器隐藏的原生操作

下表是隐藏清单，**不是 Web 缺陷清单**。普通浏览器页面不拥有用户的操作系统窗口、任意文件路径或本地进程。判断依据是动作的目标，而不是页面名称：例如要隐藏的是“拖出为 OxideTerm 桌面窗口”，不是“拖动标签”。

| 应隐藏的桌面原操作 | Web 仍应保留或另行提供 | 对照 |
|---|---|---|
| 把标签拖出为独立 GPUI 桌面窗口、合回原生窗口；窗口交通灯、桌面窗口拖动区域 | 页内重排、移到标签、分屏；网页全屏与另开浏览器标签是不同操作 | T02、T05、T07 |
| 控制本机窗口材质、桌面应用图标、需要 OS 管理权的窗口行为 | 主题、背景图、透明度、网页图标、响应式标题栏 | W05、W07、W09、W11 |
| 直接启动访问者本机 PTY、枚举系统 shell、加载本地 profile、安装 CLI、注册系统 URI 处理器 | 网关终端、应用内打开连接 URI、复制命令；网关的 “local” 不是访问者的本机 | C02、E01、S02 |
| 任意枚举磁盘、打开 Finder/Explorer 定位、启动默认外部程序、后台写指定绝对路径 | 用户选取文件/目录、上传、下载、授权范围内的编辑和浏览器预览 | F02、F05、E08 |
| 直接读写 OS 钥匙串/钥匙代理、系统提权、本机锁屏或调用桌面解锁流程 | SSH 认证、主机指纹确认、网关的授权会话；网页自身的锁定要另定义 | C03、C12、S02–S03 |
| 在访问者本机启动 MCP/ACP/IDE agent、原生插件进程、协议 helper，以及监听任意 TCP 端口 | 远端授权服务、浏览器可运行的插件、经网关的 RDP/VNC 和端口转发、受授权的浏览器设备 API | C07、C10、R04、R08、A06 |
| 激活便携安装、迁移桌面应用数据目录、收集原生进程诊断包 | 明确范围的网页数据导出、清除或下载诊断 | S02、S06 |

隐藏应同时作用于欢迎页、活动栏、右键菜单、工具栏、设置搜索、命令面板、快捷键及引导步骤。**权限尚未授予**与**平台没有该能力**要分开：例如支持 Web Bluetooth 的环境应给出“选择设备”，用户取消后仍能重试，而不是把 BLE 永久藏掉。
