## Rebuilding the animated artwork

Run `python3 scripts/assets/generate_backgrounds.py` from the repository with
NumPy, Pillow and FFmpeg (including libx264) installed. These are artwork build
tools, not application runtime dependencies. Use `--preview-only --output-dir DIR`
to inspect four phases of each composition before encoding.

Both videos are silent 16-second loops at 1600 × 1000 pixels and 24 frames per
second, encoded as H.264 with 8-bit YUV 4:2:0 color. All motion is periodic over
one cycle; the final frame precedes the first by one normal frame interval.
Encoder versions may produce different file hashes; update this manifest when
intentionally replacing a distributed asset.
